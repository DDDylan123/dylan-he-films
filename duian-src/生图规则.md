# 《对岸》生图规则（Dylan 定，2026-10-08）

1. 生图前必须核对当年的史实：建筑、天际线、街景、室内陈设、穿衣风格、交通工具、招牌字样。
   例：某年的浦东景色必须和那一年的老照片对得上（东方明珠 1994 年建成、金茂 1999 年、环球金融中心 2008 年、上海中心 2015 年封顶）。
2. 参考图只能用两类：
   - 网上查到的当年老照片（LibTV 画布里已有的 PHOTO_ / PLATE_ 节点就是这类）；
   - Dylan 已正式选用的画面（总说明里标 ★在用 的静帧，以及在用视频的画面）。
3. LibTV 里生成过但没选用的图（○未用）不能当参考，那些多半是质感不过关。
4. 出图后先由 Claude 挑一轮，统一列给 Dylan 选；不直接放进试玩版。
5. 生成前报价（见 libtv-cost-check），批量要等 Dylan 确认。
