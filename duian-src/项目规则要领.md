# 《对岸》项目规则要领

Oct 8, 2026 · @dylan

## 项目概况

《对岸》THE OTHER SHORE 现在是一部**互动影游**：1991–2016 年的上海，浦东少年阿乔在关键处做选择，走向四个结局和一个隐藏结局。内容以 GitHub 仓库 dylan-he-films 里的剧本 v2（2026-10-08）为准，与之前短片版的设定冲突时以 GitHub 为准。

| 项目 | 规则 |
| --- | --- |
| 主题 | 社会颠倒：老实人赚不到大钱，钻空子的人反而成功；另一层是「对岸」：人望了一辈子对岸，却看不见身后守灯的人 |
| 题记 | 「一九九〇年，浦东开发。在那以前，上海人讲：宁要浦西一张床，不要浦东一间房。」 |
| 形态 | 视频 + 静帧 + 旁白 + 音乐混合；普通话字幕 + 英文字幕；右上角火柴盒显示剩余火柴（共 12 根） |
| 画幅 | 2.39:1 宽银幕，写实 AI 画面 |
| 署名 | 出品人 Dylan He |
| 发布 | 免费、无服务器成本：国内 B 站互动视频，海外 itch.io 网页版；现在的原型在作品集网站 /duian/（不公开链接，不被搜索收录） |
| 源文件 | GitHub dylan-he-films：duian-src/build.py（剧情树 + 每格素材）、配音清单.txt；本地文件放 Mac 的 iCloud 文件夹「aigc 短片/互动影游 对岸」 |
| 排期 | 2026 年 10 月先做完《定位》，再做《Pobby》；《对岸》慢慢做 |
| 花钱前提 | 互动框架定下来之前，不花 LibTV 积分 |

## 故事与结构

剧本 v2 是一棵有 5 个选择点、四个结局的剧情树；每个结局都要让玩家为那个选择付出真实代价，没有白来的结局。

**人物**

| 人物 | 设定 |
| --- | --- |
| 阿乔 | 浦东少年，16 岁起跟老金学修脚踏车。爸爸跟厂里支内去了外地，妈妈不肯去，过江回了浦西娘家，说过两个月来接他，再没来。每夜去江边数对岸的灯。旁白是老年阿乔（市区话） |
| 老金 | 阿乔的师傅、邻居，修车的。老实，不加楼：「弗是吾伲格，拿仔夜里困弗着。」那盒火柴是他给的。说浦东话。灶间的灯为阿乔亮了一辈子 |
| 薇薇 | 浦西人家的女儿，1991 年在码头借火，后来嫁给沈家骏，是沈家的女主人；不记得阿乔 |
| 沈家骏 | 浦西钻空子的人：一直住浦西，不卖自己的核心房产，只炒浦东房、卖浦西老破小；两次把房子卖给阿乔，都请他吃饭 |
| 沈囡囡 | 沈家的小女儿，1999 年外滩问「阿爸，对面是啥地方？」 |
| 周敏 | 替沈先生跑腿的中介，1996 年上门收房，2016 年领房客 |
| 老张 | 动迁干部；公事说市区腔，私下说浦东话，劝老金加楼 |
| 小陈 | 苏北来的建筑工人，苏北口音普通话 |
| 浦西老太太 | 阿乔的妈妈。2016 年她的浦西老屋动迁，来租阿乔的浦东房子，认不出他 |

**剧情树**

| 段落 | 年份 | 内容 | 选择 |
| --- | --- | --- | --- |
| 序幕 | 2016 → 1991 | 老阿乔划火柴；「江两边个灯，我数了廿五年。」 | — |
| 灶间 | 1991 | 老金留他吃饭、教他补胎、把一盒火柴塞进他口袋：「夜里冷，迭盒自来火拿去。」 | — |
| 码头借火 | 1991 | 末班轮渡前，薇薇问「有火伐？」 | 划一根火柴（记下「见过她」）/ 讲：呒没 |
| 加楼 | 1992 | 动迁消息来了，邻居连夜加楼；老金不加，问阿乔「侬加伐？」 | 加 → 四套房 / 不加 → 一套新村房，和老金做邻居 |
| 四把钥匙 | 1994 | 「哪能还是浦东。」老金：「依 be be 有啥好？」 | 统统卖脱，过江 / 留在浦东 → 结局三 |
| 过江 | 1995 | 四套房换弄堂里一间老公寓，窗对着沈家 | — |
| 周敏上门 | 1996 | （不加楼线）浦东涨了一点，刚好够动心 | 卖掉买亭子间（记下「卖了」）/ 勿卖 → 结局四 |
| 饭局 | 1995 或 1996 | 沈先生请新邻居吃饭；她拿烟，阿乔的手比脑子先动，沈先生的打火机先点着；「侬老底子是阿里人？」「……浦东。」她侧身对丈夫轻声说「浦东啊？乡下头呀。」 | 笑笑，坐下去 → 结局一 / 起身，走出去 → 结局二 |

**结局**

| 结局 | 一句话 | 结尾卡 |
| --- | --- | --- |
| 一 · 对岸 | 他得到了对岸，对岸没有得到他。 | 人望了一辈子对岸。对岸也在望，望个是另一个对岸。 |
| 二 · 掼脱 | 他保住了自己，却把两岸都弄丢了。 | 人一生最远个路，是半条江。 |
| 三 · 赢家 | 他赢了这个时代。对岸终于自己走到他面前，他却开不了口。 | 立得再高，也看不见自家身后。 |
| 四 · 老金的窗 | 他少拿了三套房，一辈子没过江，最后连守灯的人也失去了。 | 有人一辈子去对岸点灯，有人一辈子在身后守灯。 |
| 隐藏 · 灯 | 四个结局都看过后，标题页多出一根没用过的火柴。全剧唯一一次老金自己开口（只出字幕）：1991–2016，灶间的灯夜夜开到天亮，「四条路上，我一夜也没关。」 | — |

不同的选择会改变同一个镜头的旁白：见过她的，饭局上是「火柴换成了吊灯。是伊。」，没见过的是「伊是沈家个女主人。」；1999 年外滩也分「回头看了一眼」和「没认出我」。

**火柴**：老金给的一盒 12 根。借火用掉一根；1999 年剩三根；2016 年划最后一根。结局二把火柴盒掼进黄浦江——「我掼脱个，是老金个自来火。」

**写作要求**

- 镜头讲发生了什么，旁白只讲心事；要看得懂，但不靠解释。
- 剧本要有文学性、深度和哲理，尾韵荡气回肠，克制、高级，像《繁花》；不是普通小游戏。
- 核心场次拍成多机位的完整戏，不要一件事一个镜头（那样像 PPT）。
- 每个角色都要有人物小传和关系；所有分支写完要自查逻辑和前后衔接。

**地理与史实**

- 老金家在东方明珠**背后**（东边），从外滩看不见。结局一的最后是反打到楼群背后老金的窗，是全片唯一不动的镜头。
- 饭局问的是「老底子是阿里人」（出身），不是住址——阿乔已经住在浦西。
- 1999 年外滩那对父女是沈家骏和沈囡囡，和饭局上的丈夫是同一个人。
- 不加楼线 1994 年搬进的是新建的新村（画面待改）。
- 每个年代的楼宇、手机、衣着都要对年份；1999 年陆家嘴只有东方明珠和金茂，不能有环球金融中心、国金中心。

## 视觉与美术规则

始终保持王家卫的电影质感：人物穿现代衣服，味道靠光、色、构图和姿态出，不靠服装。

**画面怎么做**

- 光：一两盏实景灯（红灯罩、火柴、吊灯）打出一块光，其余压暗。禁用顺光、大厅顶光——那是电视剧、红果短剧的拍法。
- 色：深红、墨绿、黑，饱和、光晕重、胶片颗粒。
- 构图：偏心构图；前景挡人（肩背、玻璃、花、窗框、晾衣杆）；镜子里的倒影。
- 镜头语言：同一个构图重复出现让观众自己认出来（火柴照脸 ↔ 吊灯照脸）；情绪顶点用抽帧拖影和定格；中段快剪、核心场慢；结尾老金的窗是全片唯一的固定镜头。

**造型**

- 年代感交给道具（大哥大、没牌子的烟盒、玻璃烟灰缸），不交给衣服。
- 《花样年华》里的老上海腔调，放在环境（外滩老饭店、深木墙、金框镜）和姿态、表情上。
- 薇薇 1991：白衬衫、米色开司米开衫、短发、珍珠耳钉，清纯。
- 薇薇 1995 定稿：黑色细针羊绒高领、淡绿翡翠镑（祖传）、小珍珠耳钉、下巴长利落短发、深红唇；只抽细长女士烟，两指夹、手腕外翻、烟只冒一缕；眼神低垂侧看，冷、私密。她品位极好。
- 阿乔 1995：新买的、略反光的藏青双排扣西装，头发抹油，穿得太用力——他的土是故意的。
- 老金：始终是蓝色工作服，在一盏灯泡下。

**禁忌**

- 生成薇薇时，脸参考只放 1991 原版一张，不叠其他人物图（会串脸，变老变丑）；造型全部用文字描述。
- 不出现像日本国旗的画面（纯色背景上的红色圆盘）。

## 声音规则

方言必须地道，否则这部片不值得做；旁白用最早的原声，不做任何变调处理。

- 上海人说上海话（沪语）；外地人说家乡话，只用上海话、浦东话、苏北话这几种，不加四川人等。
- 上海市区话可以用 AI 生成。
- 浦东话找不到人录，全片尽量少用；必须用时，严格考证发音，写成「浦东话汉字 + 难读字插拼音」交给 AI（例：伊板板读 yi be be，火读 hu）。
- 所有声音先生成给出品人确认，再生成镜头。
- 旁白用最早那版原声的声音（慢、有回忆感）。旁白是老年阿乔（市区话）。剧本 v2 有大量新旁白，待配音的都列在 duian-src/配音清单.txt；新配的要和最早那版原声像同一个人。拿到的录音不做降调等处理，会有机器味。
- 对白镜头用生成视频自带的音轨，口型才对得上；旁边的人必须有动作，不能定住。
- 音乐：以 GitHub 当前用法为准（1991 和多数段落用大提琴华尔兹主题，1992–1994 加楼段用「对岸主题 v1」，饭局用现场老上海爵士小乐队，隐藏结局不配乐）。以后新做的配乐避免小提琴主奏（《回信》已用弦乐），可选钢琴、班多钮手风琴、闷音小号、颤音琴、吉他。
- 声音设计当节拍用：划火柴、轮渡汽笛、打火机「咔」一声。

**待配音重点（以 GitHub 为准）**

- 老金的台词是浦东话，已录好四句：「吃仔饭再去」「修修还好用格」「夜里冷，迭盒自来火拿去」「依 be be 有啥好」；「弗是吾伲格……」里的「吾伲」写作「五泥」交给 AI。老年老金的声音待生成。
- 隐藏结局里老金自己的话只出字幕，不配音。
- 饭局「浦东啊？乡下头呀。」现在是旧的阿姨声音，要用薇薇的声音重配，轻声耳语。
- 1999 年外滩父女对白暂用旧 S24 音轨，父亲要换成沈家骏的声音。
- 年轻阿乔的「加」、老张私下那句是浦东话；周敏、沈家骏、薇薇、浦西老太太说市区话。

## 生成工具与成本规则

《对岸》的画面只用 LibTV 生成；每次生成前先报积分、折合人民币和占余额的比例，出品人点头再动手。

| 类别 | 用什么 | 大约多少（LibTV 积分） |
| --- | --- | --- |
| 关键帧、定妆 | 只用 LibTV（Seedream 5.0 Pro / Lib Image 2.5 S）；不用 GrsAI 等其他平台 | Seedream 5.0 Pro 约 16/张，Lib Image 2.5 S 约 34–38/张 |
| 视频 | LibTV：默认 Kling 3.0 / O3；大动作、复杂运镜、对口型才用 Seedance 2.0；不用 2.5；不用 Higgsfield | Kling 约 55/5 秒；SD2.0 Mini 约 80；SD2.0 VIP 约 135 |
| 配乐 | 先用 Suno（会员积分，在出品人的 Chrome 里操作，只下载选中的）；Suno 做不了再用 LibTV ElevenMusic | ElevenMusic 约 360/首 |
| 人声、音效 | LibTV Seed Audio / Minimax | Seed Audio 约 2/条 |

**价格基准**：会员积分约 0.016 元/分（每月 2–3 号清零重置）；加量包约 0.035 元/分（30 天有效）。

**工作顺序**：先出关键帧 → 做静帧预演给出品人审 → 审过再花积分生成视频。

**LibTV 已知的坑**

- 老的图片/音频节点有历史残留，生成时会发送旧图。一律用图片地址新建节点做参考，生成后核对实际发送的图。
- 积分用完时报「商业限制（COMMERCIAL\_BLOCKED）」，不是提示词问题；先查余额。
- 生成调用常超时但任务仍在跑：用任务号查结果，不要重新提交，避免重复扣分。
- Kling 不听「镜头不动」的指令；人群拖影用 Seedance 2.0 直出，后期叠帧会有鬼影。
- Seedance 对口型时，提示词里必须给旁边每个人写动作，否则会定住。
- seed-audio 不支持用音频做声音参考，克隆不了原旁白声音。

## 交付与工作流程

每一版都用浏览器能看的网页交付，所有有用的素材存到本地项目文件夹。

- **交付**：网页预览链接，带全屏按钮；只有明确要求时才导出视频文件。
- **先审再花**：先用关键帧做便宜的静帧预演，审过再生成视频；声音也先生成供确认。
- **存档**：生成的片段、定稿镜头、音乐、剪辑版本都存进 Mac 的 iCloud 文件夹「aigc 短片/互动影游 对岸」；废弃的标清楚「未用」。
- **署名**：出品人 Dylan He。
- **沟通**：用中文；出品人不在时可以自己往下做，卡在必须出品人拍板的地方再停。
- **每次改版都要自查**：地理、年代、衣着、人物前后是否对得上（例：饭局丈夫和 1999 年的丈夫必须是同一个人）。

**互动原型怎么做（GitHub dylan-he-films）**

- 剧情树和每格素材只写在 duian-src/build.py；运行它生成 duian/index.html 和 配音清单.txt，两个产物都不手改。
- 新素材按 img\_*.webp / vid\_*.mp4 / aud\_\*.mp3 命名放进 duian-src/new/（不进 git），在 build.py 里引用后重新生成；素材编号记在 media\_map.json，已有编号永不改。
- 还没生成的画面先用占位格（文字描述 + 「待补静帧」），剧情先跑通。
- 每格都有普通话字幕和英文字幕；台词原话用沪语写法记在 line。
- 线上版媒体走 jsDelivr，失败退回 GitHub Pages；不用 Google Fonts（国内打不开）。原型放在 /duian/，不链接、不被搜索收录。
- 玩家看过的结局记在浏览器本地；四个都看过才解锁隐藏结局「灯」。
